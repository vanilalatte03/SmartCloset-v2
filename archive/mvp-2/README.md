# SmartCloset MVP 2 Archive

이 문서는 SmartCloset 2차 MVP를 이해하기 위한 최소 요약이다.

- 아카이브 정리 시점: 2026-05-22
- 상태: 2차 위치/프론트 MVP 완료 후 3차 인증/개인화 문서 전환
- 목표: 사용자별 위치 저장과 React+Vite+TypeScript 프론트엔드 앱으로 실제 사용 흐름을 검증한다.
- 최종 범위: 사용자 위치 저장, 내장 대표 격자 catalog, 위치 선택 API, 사용자 위치 기반 KMA 호출, React 프론트엔드, Docker Compose 프론트 포함 공유

현재 구현 기준 문서는 루트 `README.md`와 `docs/` 아래 문서다. 이 archive는 과거 MVP 맥락 확인용이며 구현 source of truth가 아니다.
