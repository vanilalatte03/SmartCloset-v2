# MVP 2 Changelog

## 2026-05-22
- 2차 MVP 문서를 3차 인증/개인화 기준으로 전환했다.
- 2차 MVP 전체 문서 복사본을 남기지 않고, 과거 맥락 확인용 최소 archive 요약으로 정리했다.

## MVP 2 종료 시점 주요 변경
- 사용자별 위치 저장을 추가했다.
- 내장 KMA 대표 격자 catalog 조회와 검색을 추가했다.
- 사용자 위치 선택 API를 추가했다.
- 추천 생성 시 사용자 위치 `nx`, `ny`로 KMA 단기예보를 조회하도록 정리했다.
- seed user 기본 위치를 서울특별시로 문서화했다.
- React+Vite+TypeScript 프론트엔드 앱을 추가했다.
- Docker Compose 공유 흐름에 프론트엔드 서비스를 포함했다.
- 로그인/회원가입과 인증 사용자 기반 API 전환은 3차 MVP 범위로 넘겼다.
