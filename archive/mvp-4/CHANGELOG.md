# MVP 4 Changelog

## 2026-05-25
- 4차 MVP 문맥을 MVP5 문서 작성 준비를 위해 archive로 정리했다.
- 4차 MVP 전체 문서 복사본을 남기지 않고, 과거 맥락 확인용 최소 archive 요약으로 정리했다.

## MVP 4 종료 시점 주요 변경
- 보호 API `GET /api/weather/current`를 추가했다.
- React 앱을 Today, Closet, Preferences, Location, History 중심으로 재구성했다.
- 로그인 후 기본 view를 Today로 설정했다.
- 첫 추천 준비 체크리스트를 추가했다.
- 추천 실패 코드에 한국어 안내와 직접 CTA를 연결했다.
- 추천 결과에서 옷 조합과 추천 이유를 먼저 보여주도록 했다.
- Closet view에 카테고리 필터, 빠른 등록, 계절/기온 프리셋, 수정, 보관 처리를 추가했다.
- Preferences view를 swatch/chip/tag 입력 중심으로 정리했다.
- Location view를 현재 위치 카드, 날씨 요약, catalog 검색 결과 중심으로 정리했다.
- History view를 최신순 추천 이력 카드와 상세 펼침 구조로 정리했다.
- 데스크톱 sidebar와 모바일 bottom tab을 적용했다.
- Docker Compose 공유 문서와 데모 시나리오를 MVP4 기준으로 동기화했다.
