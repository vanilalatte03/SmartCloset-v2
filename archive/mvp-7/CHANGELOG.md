# MVP 7 Changelog

## 완료

- MVP7 위치/날씨 신뢰도 phase 완료
- KMA 행정구역 catalog resource와 동네 검색 API 확장
- 브라우저 좌표 resolve API와 KMA grid 변환 추가
- 위치 저장 source 추가
- `forecastPeriod` 기반 weather input 선택 추가
- `WeatherResponse`의 location/source metadata 추가
- 추천 결과와 이력의 위치/날씨 source snapshot 저장과 응답 추가
- Location/Today/History 프론트 UX 동기화
- MVP7 QA 기록 작성

## 후속

- MVP8에서 refresh token, 이메일 인증, 비밀번호 재설정, Google login, 세션 만료 UX, 계정 삭제를 다룬다.
- MVP8에서는 AWS를 구현하지 않고 MVP9 AWS 배포에서 교체할 어댑터 경계만 준비한다.
